## 第十六阶段

标题与背景先填写，分组、优先级、今日安排在其后；截止与提醒、循环按需展开。速记仅显示标题、内容与分组。外部点击、关闭和 Esc 都保留当前页创建草稿，再次新建恢复；显式取消放弃。标题与每周循环有内联校验，支持 ⌘ / Ctrl + Enter 保存。截止与循环、标题编辑共享340px属性面板。新增资源为 `demos/loop-task-phase16.css` 和 `demos/loop-task-phase16.js`。

## 第十七阶段

完成前统一展示结论和未完成节点，可直接进入对应任务补充结论或定位节点；满足规则即完成。创建与完成后在工作区顶部显示一条操作反馈：查看今日／日历，或查看结果／回顾／撤销。撤销保留处理内容及循环本次状态；日历与回顾打开任务后返回保留范围、日期与滚动位置。日历中已完成任务使用结论摘要。

新增资源为 `demos/loop-journey-phase17.css`、`demos/loop-journey-phase17.js`。浏览器检阅入口：[第十七阶段](http://127.0.0.1:4186/loop-plane-phase1.html?phase=17)。离线请保留整个 `demos/` 文件夹及其脚本、样式、assets、vendor。所有任务操作均为页面内示例，不影响正式数据。
