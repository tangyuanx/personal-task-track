# Loop v0.1.221

恢复处理流节点的右键添加、长按调整层级和双击改名。

- 右键节点后可添加兄弟节点或子节点；兄弟节点插入当前节点后面，子节点加入当前节点下一层。
- 菜单复用现有任务右键菜单的圆角、边框、配色、阴影、字号和图标规格，适配浅色与深色主题。
- 打开或关闭节点右键菜单不重建处理流和详情编辑器，保留当前选择、记录草稿与滚动位置。
- 新增后在对应层级直接输入标题，Enter 确认、Esc 取消；向折叠节点添加子节点会自动展开。
- 修复子节点重复显示输入框、标题输入状态丢失，以及节点旁加号无法正确新增子节点的问题。
- 支持 Shift+F10 打开菜单、方向键选择、Esc 关闭及窗口边缘定位。
- 保留 v0.1.220 的处理流滚动位置修复。

- 长按节点标题后拖动，可调整兄弟顺序、移入其他节点或移回顶层；保留整个子树和记录，禁止循环层级，支持 Esc 或失焦取消。
- 双击节点标题打开现有改名浮层，支持输入校验、保存和取消；修复首次点击重绘导致双击失效的问题。
- 拖放反馈沿用当前界面的配色和圆角，拖动结束不会误触节点详情或改名。
