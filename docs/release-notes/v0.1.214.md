# Loop v0.1.214

第28阶段：操作连续性正式接入桌面应用，保持既有布局、编辑器与保存/恢复能力。

- 页面和操作组采用200ms连续切换；快速反向从当前视觉位置接续。
- 支持操作组移动时系统鼠标逐显示帧跟随，保留点击处的像素偏移；仅可信直接点击启动，用户移动、键盘输入、失焦、窗口变化或过期立即取消。
- 增加设备本地的连续切换与鼠标跟随开关；系统减少动态效果时关闭相应位移。
- 记住各任务、页签及节点的阅读位置；收起节点保持锚点，关闭详情后焦点回到原节点。
- macOS安装包携带原生CoreGraphics适配器；Windows安装包携带固定User32适配器，无Python运行依赖。

验证：253项应用测试、11项反馈服务测试通过；真实Electron隔离数据回归覆盖六方向切换、长内容滚动、编辑器实例保留及焦点恢复。同内容Demo与正式应用关键区域几何对照无超过1px差异。macOS x64/arm64与Windows x64完整构建、原生资源携带和跨平台更新摘要校验通过。

实体鼠标手感、Windows及多屏混合DPI尚未完成实机验证；macOS签名安装环境和其他系统版本亦需后续检验。自动化合成点击不计作实体鼠标验收。
