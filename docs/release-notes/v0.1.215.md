# Loop v0.1.215

修复任务分组、今日与任务仓库切换时的编辑器重建，以及处理流、知识笔记和历史处理切换时偶发的鼠标跟随中断。

- 同一操作期间的状态或草稿重绘延续原动画和鼠标跟随；任务、节点或操作目标改变时仍按原保护条件取消。
- 复用未变化的工作台、页签和最近使用的笔记编辑器，保留编辑状态；避免重复绑定事件。
- 修复快速切换或外部重新加载时，笔记可能一直停留在“正在打开”的问题，防止旧初始化结果覆盖新文档。
- 合并自动保存并将完整数据比较移出点击处理路径；退出、导出等显式保存保持立即执行。相同长度的笔记和历史内容变化也能正确保存。

Apple Silicon Mac 请使用文件名含 `arm64` 的原生版本。本机对照中，Intel 版经 Rosetta 运行有明显切换延迟；原生版本恢复正常。此结果不代表所有 Intel 设备的性能。

用户已验收本地原生候选，确认切换恢复正常。255 项应用测试、11 项服务测试及两组真实 Electron 界面回归通过。自动化鼠标协议回归使用模拟 IPC，不代替 Windows、多屏混合 DPI 等环境的实体鼠标验证。
