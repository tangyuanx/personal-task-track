# Loop v0.1.216

完善累计 Demo 在真实应用中的交互、保存、恢复与桌面操作体验。

- 双击任务名称即可输入，保留左侧完成按钮；点击其他位置自动保存。新建任务弹窗点击外部关闭，并保留未提交草稿。
- 知识笔记文件菜单补齐分区与独立导出入口；修复打开笔记、切换页宽产生的错误修改状态，保留 Markdown 原文和图片。底部保存状态反映真实的排队、写入、成功与失败。
- 补齐完整使用手册、文章搜索、目录、功能跳转及返回位置。完善日历、回顾的日期校验、任务跳转与返回上下文。
- 修复删除失败后的保存回滚、批量恢复、分组冲突及旧归档兼容，保留任务、节点、笔记和分组的恢复能力。
- 修复顶部控件重复或丢失、原生窗口状态竞态、导航收起后的指针跟随身份和切换后的滚动回跳；新输入可立即接管，菜单在窗口缩小时保持可操作。
- 完善设置保存、备份进度、完整恢复校验与失败保护。连续切换、鼠标跟随和工作导航开关随完整备份保留；修改默认任务范围时保持设置页。
- 更新失败后按原阶段重试检查、下载或安装，避免重复操作。更新偏好写入失败时保留原设置并显示失败。
- 浮窗添加速记保留主窗口正在查看的节点；拒绝空标题。从设置或筛选页跳转任务时，正确显示目标任务。

Windows 实机界面、鼠标及安装升级行为由用户在 Windows 环境继续验证，本轮未将其计为通过。
