# Loop v0.1.225

修复知识笔记按 Ctrl+S 后误报“文件已被外部修改”，以及明确覆盖后提示再次出现的问题。

- 图片保存为附件时，同步编辑器中的 Markdown 引用；后续刷新、编辑和再次保存不会恢复临时图片路径。
- 保存后按本次写入的文件哈希核对结果，不再拿当前编辑草稿与磁盘正文比较。
- 保存过程中继续输入的内容保留为未保存草稿，并保留 Recovery；不会被保存回执覆盖或误报为文件冲突。
- 保留真实外部修改的冲突检测、明确覆盖与源码模式保存，保存图片时保留编辑器、选区与撤销历史。
- 知识笔记页脚在字数与保存按钮左侧增加柔和红色提示：“知识笔记功能不完善，暂不建议使用”。
