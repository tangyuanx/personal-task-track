# Loop v0.1.218

修复笔记输入与自动保存，简化节点记录，并完善菜单关闭、默认字体和笔记页宽。

- 修复知识笔记在暂停输入、自动保存后失去焦点的问题；中文输入、撤销与重做和 Markdown 源码编辑继续保留草稿。
- 工作台“完成任务”右侧的三点菜单支持点击外部关闭，外部控件继续响应本次点击；按 Esc 关闭并将焦点返回菜单按钮。
- 中文默认使用黑体，英文默认使用 Times New Roman，主窗口与今日浮窗保持一致；保留已有的字体选择，系统未安装相应字体时沿用后备字体。
- 节点记录面板仅保留处理记录编辑区和关闭按钮，暂时移除标题、路径、状态、节点操作、预览、导出、展开和前后节点切换；已有节点数据保留，处理流仍可管理节点。
- 修复处理记录自动保存漏写的问题，输入后切换节点或关闭面板也会保存到对应节点。
- 修复笔记“默认 / 较宽 / 全宽”在较窄窗口或显示大纲时无区别的问题。三档分别使用可用空间的 72% / 88% / 100%，前两档保留 840px / 1120px 上限；编辑、Markdown 与预览共享页宽设置。
