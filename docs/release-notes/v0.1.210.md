## 任务与分组编辑：原位改名、管理面板与真实保存

以冻结的第 24A 阶段基准（`loop-management-phase24.css/js` v4 + `MANIFEST.sha256`，全程未修改）为唯一标准等效复现。

- **原位改名**：双击列表任务名、双击导航分组名，右栏任务标题点击即进入输入；点击任意其他位置（含不可聚焦的文字与背景）自动保存，Enter 保存、Esc 撤回。名称后没有确认按钮，也没有「点击别处保存／Esc 取消」一类提示。
- **统一的输入外观**：三种原位命名都是透明背景、无整圈边框、1px 细底线、零圆角、无阴影；属性面板的普通字段继续沿用 Phase22 的弱边框与 6px 圆角，两者语义不同、不做混用。
- **分组行**：每行只有身份标识、名称与右对齐数量，不再有单独的管理按钮；「任务分组」右侧保留集中整理与新建入口，每组操作走右键菜单（200px、34px 行高、14px 图标列、图标与文字左对齐、上/下箭头方向正确、边界项禁用），并保留 F2 改名与 Shift+F10／菜单键打开菜单。
- **属性面板**：360px、18px 内边距、主体可滚动，标题／分组／优先级（高·中·低三段）／手动今日·卡住·稍后，以及按需展开的「时间与安排」（截止日期与时间、提醒、循环与进入今日的时间、重复日期、预计时长）。未提交的草稿按任务稳定 ID 保留，A→B→A 各自恢复；显式取消或成功保存只清当前对象；只有真实写入成功后才有回执。
- **迁移**：330px，目标分组可搜索并包含未分组，显示计数与无匹配状态；只改变归属，不动今日安排、处理流、简报与笔记；移动后保留来源列表与筛选，并提供「前往目标／返回列表」。
- **删除分组**：390px 影响说明，默认保留内容并迁至未分组或指定分组，选择同时删除才展开额外影响与理解确认；若该组是成长来源，必须显式替换或停用；撤销入口保留 12 秒，只回滚仍未被后续修改的记录。
- 分组一律使用稳定 ID，保留已有同名分组，重命名不改变归属；不改名外部 Markdown 与附件。

验证：`npm run check` 全绿（渲染器 231 项 + 服务 11 项）；同条件比对 54 组（9 状态 × 3 视口 × 2 主题）无成块差异，浮层几何逐值相同（菜单 200×204、集中整理 510×403、属性 360×439、迁移 330×418、删除影响 390×335）；真实交互与读写已复核：改名、分组、顺序与属性重启后读回，删除保留内容与撤销、选择删除内容均按真实结果执行。
