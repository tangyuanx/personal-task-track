## Mac / Windows 一体化标题栏：单行 48px 顶栏与系统原生窗口控件

以冻结的第 25 阶段基准（`loop-plane-phase25-candidate.html` + `loop-window-phase25.css/js` v2 + `MANIFEST.sha256` / `DEPENDENCIES.sha256`，全程未修改）为唯一标准等效复现；Demo 的窗口控件是浏览器预览，生产端保留系统原生控件，不绘制任何 HTML 副本。

- **一行 48px 顶栏**：移除独立的系统标题带，身份区从导航列移入同一行并跨三栏，导航自其下方开始并保留 12px 上内距；正文三栏列宽、主题、字号、面包屑、日期、今日浮窗入口与更新状态全部沿用。
- **Windows 左上角**（含最后反馈版修正）：身份区宽度绑定侧栏实际 `--nav-width`（1894px→200、1280px→184、1024px→154），不再固定 184px；完整状态按「项目图标、Loop、收起导航、更新」排列，收起与更新位于品牌区右侧同一行；导航收起后侧栏与品牌区同为 64px，仅居中显示图标，收起／更新组成相邻顶栏工具区，之后是面包屑（16px 间隔）。
- **Mac**：红黄绿系统控件保留并用 `trafficLightPosition` 调整到与 Demo 同一位置；其后依次是实际图标、Loop 与更新；导航收起按钮位于相邻顶栏位置，收起后仍保持这一行（不继承旧的纵向排列）。
- **右侧窗口控制**：使用隐藏标题栏 + 窗口控制覆盖层保留系统最小化／最大化还原／关闭，Snap、系统菜单、Alt+F4、双击标题与边缘缩放等原生能力全部保留；安全区宽度读取 `navigator.windowControlsOverlay.getTitlebarAreaRect()`（随 DPI 变化），不使用固定 138px。
- **真实窗口状态**：活动／最大化／全屏由主进程真实事件同步（`data-window25-inactive/maximized/fullscreen`），主题变化把应用画布与文字色发布给原生覆盖层；更新按钮搬出品牌区后仍保持自身相对定位，提示点继续附着按钮。
- **保留既有能力**：关闭仍走 `close → app.quit` 与退出前笔记草稿 flush（未改为隐藏／托盘／destroy）；最小化后提醒与今日浮窗继续可用；导航收起、日期与浮窗入口连接原处理器；浮窗、原生对话框、导出隐藏窗口不受影响。

验证：`npm run check` 全绿（桌面 174 项 + 服务 11 项）；Demo 与应用在 15 个状态（Mac/Windows 排布、浅/深色、活动/非活动、展开/收起、更新四态、1894 宽）逐节点几何与计算样式比对 **0 差异**；真实窗口操作 36 项通过（最小化/还原、最大化/还原、全屏进出、失焦/恢复、缩放、真实关闭并在退出瞬间落盘草稿、重开恢复）；Windows 应用绘制部分 17 项通过。未消除项：macOS 原生红黄绿为 14px、中心间距 23px（Demo 模拟 12px / 20px，系统自绘，只能设置组原点，关闭控件中心已与 Demo 完全一致）；Windows 实机的原生覆盖层外观、Snap、DPI 矩阵与真实拖动／双击／边缘缩放本机无法验证。
