# Loop v0.1.226

- 处理流工具栏新增“隐藏已完成 / 显示已完成”开关，默认显示全部，并在本机记住选择。
- 隐藏已完成父节点时，其未完成子节点仍按原有树形缩进呈现；父节点原本折叠也不会遗漏待办。
- 筛选仅影响显示，节点层级、顺序、记录、折叠状态及完成统计均保留。
- 开启筛选后，新完成的节点自动隐藏，编辑中的节点记录继续自动保存；全部完成时显示说明，仍可添加新节点。
- 定位节点遵循当前筛选范围，切换任务及重启后保持显示偏好。

验证：`npm run check`（309 项桌面/模型测试及 11 项服务测试）、处理流筛选 UI 回归、节点交互回归、`git diff --check`。UI 验证覆盖混合层级、折叠父节点、状态变化、记录保存、滚动保持、重启及 1024px 最小桌面窗口的浅/深主题。
