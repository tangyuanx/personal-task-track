> 本文档仅记录最终确认或待确认需求，不包含已验证失败的尝试。

------------------------------------------------------------------------

# 修改原则

-   基于当前 main 分支修改。
-   保持现有业务逻辑不变。
-   不修改任务数据结构。
-   所有新功能兼容 Electron 与浏览器。
-   后续修改不得破坏已确认修改。

------------------------------------------------------------------------

# 修改001：左侧 Sidebar 高度修复（已确认）

## 问题

当新建一个没有任务的分组时：

-   任务分组
-   设置
-   自动保存
-   任务回顾

整体会上移，下方出现大面积空白。

添加第一个任务后恢复正常。

## 最终要求

无论当前分组是否有任务：

-   Sidebar 始终铺满整个窗口；
-   Task List 使用剩余空间；
-   Group Panel、Settings、Auto Save、Task Review 始终固定在底部区域；
-   任务数量不能影响 Sidebar 高度。

## 验收

-   空分组时底部区域保持贴底。
-   添加第一个任务后位置保持不变。
